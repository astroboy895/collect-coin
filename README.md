# Collect Coin

Aplicación Android inicial para registrar monedas argentinas y mundiales.

## Funciones incluidas
- Registro local de monedas.
- Campos de país, denominación, año, material, peso, diámetro, conservación, valor, catálogo y observaciones.
- Ficha individual en pantalla.
- Impresión de ficha individual y catálogo completo mediante el servicio de impresión de Android (permite guardar como PDF si está disponible).
- Datos almacenados localmente en el dispositivo.

## Compilar
El flujo de GitHub Actions puede compilar `app/build/outputs/apk/debug/app-debug.apk`.
